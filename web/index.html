    Everything here runs in this tab. Your program is compiled and executed
    by a WebAssembly build of the Origin compiler inside your own browser. It is never
    uploaded, and no server — including the one that served this page — ever sees
    it or runs it.
  

  

    Your program is kept in this browser’s local storage so it is still here when you
    come back. It stays on this device, is not synced anywhere, is not visible to whoever
    runs this site, and is lost if you clear site data.
    
  

  

    Copy link puts the whole program in the link itself, after the
    #, which browsers never send to a server. Nothing is stored, so a link
    cannot expire or be taken back — whoever has it has a copy of the program.
